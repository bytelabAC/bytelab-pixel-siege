A pull-and-fling physics game for WordPress, drawn entirely with the BYTELAB Pixel Flask identity.

== Description ==

BYTELAB Pixel Siege turns the brand system into a game. Byte Navy surfaces, Lab Cyan blocks and a single Spark Amber accent — no gradients, no shadows, sharp corners, exactly as the style guide asks.

The player drags a pixel bird back on a slingshot and lets go. Towers of Panel Navy and Cloud White blocks topple, glass shatters, and every bug you clear adds to the score. Twenty hand-authored levels, three bird types, three star ratings and a local high score per level.

* Twenty levels, from one hut to a full lab keep and a four-storey flask
* Real rigid-body physics (rotating blocks, friction, stacking) written for this plugin — no third-party library
* Three birds: BYTE (balanced), BOLT (dash on tap), SPARK (explodes on tap)
* Brand fonts (Vazirmatn + JetBrains Mono) self-hosted under the SIL OFL, no font CDN
* Stars, best score per level, saved in the browser; optional site-wide leaderboard with a built-in board UI
* Custom levels authored as JSON in the settings screen, validated server-side
* Responsive canvas, keyboard controls, reduced-motion support, screen-reader announcements
* Optional score saving for guests, rate limited and sanitised

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/`, or install the ZIP from Plugins → Add New → Upload Plugin.
2. Activate the plugin.
3. Place `[bytelab_pixel_siege]` in a post, a page, or a block.

== Frequently Asked Questions ==

= Does it need any external library or CDN? =

No. All physics, rendering and sound are generated by the plugin itself; nothing is loaded from a third party.

= Where are scores stored? =

The best score per level is stored in the visitor's browser (localStorage). If the leaderboard is enabled, submitted scores are also stored in a dedicated database table.

= How do I add my own levels? =

Paste a JSON array in Settings → BYTELAB Pixel Siege → Custom levels. Blocks can be placed by centre (y) or by the surface they stand on (baseY); bugs accept y or surfaceY. See README.md for the full format.

= Do the fonts come from a CDN? =

No. Vazirmatn and JetBrains Mono ship inside the plugin and are served from your own domain.

= Can I change the colours? =

The palette is part of the BYTELAB brand system, so it is fixed on purpose. Title text and level order are configurable.
